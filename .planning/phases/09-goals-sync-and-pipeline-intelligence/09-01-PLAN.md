<objective>
Add user goals text area to PWA Preferences page, extend the LLM scoring prompt to include goals, add pull sync for user_profile goals fields, and implement the rescore trigger so existing contacts get rescored when goals change.

Purpose: Users can define broad networking objectives that directly influence which contacts score as WARM_LEAD via the goal_alignment dimension. Goals flow from PWA (cloud write) through pull sync to the local pipeline's scoring prompt. When goals change, existing scored contacts are marked for rescoring so the queue reflects updated priorities.

       ```python
       # Step 2b: Check for goals rescore trigger
       # When user changes goals in the PWA, a UserPreference row with
       # pref_type="rescore_trigger" is written. We batch-clear scored_at
       # on up to 10 contacts per run so they get rescored with the new goals.
       # The trigger row is deleted once all affected contacts are rescored.
       try:
           from src.database.models import UserPreference
           with get_session() as session:
               trigger = session.exec(
                   select(UserPreference)
                   .where(UserPreference.pref_type == "rescore_trigger")
                   .where(UserPreference.pref_key == "goals_updated_at")
               ).first()

               if trigger and trigger.pref_value:
                   from datetime import datetime as dt
                   trigger_ts = dt.fromisoformat(trigger.pref_value.replace("Z", "+00:00"))

                   # Find contacts scored before goals changed
                   stale = session.exec(
                       select(Connection)
                       .where(Connection.scored_at.isnot(None))
                       .where(Connection.scored_at < trigger_ts)
                       .limit(10)
                   ).all()

                   if stale:
                       for conn in stale:
                           conn.scored_at = None
                       session.commit()
                       results["rescore_cleared"] = len(stale)
                       logger.info("Goals rescore: cleared scored_at on %d contacts (batch)", len(stale))
                   else:
                       # All contacts rescored — remove trigger
                       session.delete(trigger)
                       session.commit()
                       results["rescore_trigger_cleared"] = True
                       logger.info("Goals rescore: all contacts rescored, trigger removed")

                   steps_completed.append("rescore_trigger")
       except Exception as e:
           logger.warning("Goals rescore trigger check failed: %s", e)
       ```
