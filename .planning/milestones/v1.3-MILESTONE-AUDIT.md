### Phase 12: Enrichment Audit & Schema Extraction
- **Private symbol import:** `enrichment_extractor.py` imports `_classify_seniority` from `dashboard_service` — fragile coupling, no test coverage for this dependency path

### Phase 13: Contacts Browse Page
- **Industry display inconsistency:** Browse page shows normalized `enriched_industry` ("Technology") but contact detail page reads raw `company_industry` ("Computer Software") — confusing UX when drilling into a contact
- **Implicit script load order:** `contacts.js` depends on `escapeHtml()` from `queue.js` via global scope — no guard or import declaration; `SIGNAL_ACTIONS` has a `typeof` guard but `escapeHtml` does not

### Phase 14: Search Bar
- **Pre-existing test failure:** `tests/test_phase1_infra.py::test_gmail_not_configured_without_password` — failing since before Phase 14; `is_gmail_configured()` returns True when `GMAIL_APP_PASSWORD` is missing
- **Role filter consolidated:** BROWSE-02 standalone role filter replaced by SEARCH-01 search bar — tests pass via compatibility assertion, but discrete role filter no longer exists
- **Headline not searchable:** `enriched_headline` displayed on cards but absent from FTS tsvector and ilike fallback — intentional scope decision
- **FTS migration dependency:** `20260318000000_fts_column.sql` may need manual application to Supabase; ilike fallback masks this but degrades search quality

### Cross-Phase
- **Supabase migrations:** `20260316000000` confirmed applied; `20260318000000` (FTS) unconfirmed — search falls back to ilike if missing
