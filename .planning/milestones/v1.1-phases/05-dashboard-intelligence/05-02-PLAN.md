Add 4 new functions to `pwa/js/dashboard.js` (before `renderDashboard`), then extend `renderDashboard()` to call them.

**1. `buildHealthBreakdownSection(breakdown)`** — DASH-01
- Guard: `if (!breakdown || !breakdown.components) return '';`
- Renders insight text below the EXISTING health component metric-grid (does NOT duplicate component values — the existing 4-card grid at lines 92-109 already shows them)
- For each component in breakdown.components, render the insight string as a small text row:
  ```html
  <div style="display:flex; align-items:center; gap:8px; padding:6px 0; font-size:13px; color:var(--text-secondary);">
    <span style="width:8px; height:8px; border-radius:50%; background:${color}; flex-shrink:0;"></span>
    ${escapeHtml(comp.insight)}
  </div>
  ```
  Color: green if value >= 70, orange if >= 40, red if < 40 (same threshold as healthColor).
- Then render the top-level `breakdown.insights` array (if present, max 2 items) as a highlighted suggestion box:
  ```html
  <div style="background:var(--bg-secondary); border-radius:8px; padding:12px; margin-top:8px;">
    <div style="font-size:12px; font-weight:600; color:var(--text-muted); margin-bottom:6px;">SUGGESTIONS</div>
    ${insights.map(i => '<div style="font-size:13px; color:var(--text-secondary); padding:4px 0;">• ' + escapeHtml(i) + '</div>').join('')}
  </div>
  ```
- Wrap in `<div class="detail-section mt-4">` with header "HEALTH INSIGHTS".

**2. `buildIndustryDistributionSection(industries)`** — DASH-02
- Guard: `if (!industries || industries.length === 0) return '';`
- Header: "INDUSTRY (enriched contacts)"
- Reuse `funnel-stage` / `funnel-label` / `funnel-bar` / `funnel-fill` / `funnel-count` classes (same as `buildFunnelSection` pattern)
- For each industry item: label = industry name (width:140px), bar width = pct%, count display = `count (pct%)`
- Filter out or render last any item with industry === "Unknown" using muted style
- Wrap in `<div class="detail-section mt-4">`

**3. `buildRoleSenioritySection(mix)`** — DASH-03
- Guard: `if (!mix) return '';`
- Two sub-sections side-by-side concept, but use stacked layout (mobile-first):
  - **Top Roles** (if mix.roles exists and length > 0): header "TOP ROLES", render top 8 as funnel bars. Max pct derived from first item's count. Each bar: label = keyword, bar width = (count/maxCount)*100 %, count = count.
  - **Seniority Mix** (if mix.seniority exists and length > 0): header "SENIORITY MIX", render as funnel bars. Max count from largest tier. Each bar: label = tier, bar width proportional, count = count.
- Wrap each sub-section in `<div class="detail-section mt-4">`

**4. `buildScoreTierSection(tiers)`** — DASH-04
- Guard: `if (!tiers || tiers.length === 0) return '';`
- Header: "SCORE TIERS (scored contacts)"
- Reuse `funnel-stage` pattern. For each tier: label = tier name, bar width = pct%, count display = `count (pct%)`
- Color the funnel-fill bar: High = var(--success), Medium = var(--warning), Low = var(--danger). Apply via inline `background` style on the `.funnel-fill` div.
- Wrap in `<div class="detail-section mt-4">`

**5. Wire into `renderDashboard()`:**
- After the existing `html += buildEnrichmentStatusSection(quality);` (around line 140), add:
  ```javascript
  // Phase 5: Dashboard Intelligence sections
  html += buildHealthBreakdownSection(snapshot.health_breakdown || null);
  html += buildIndustryDistributionSection(snapshot.industry_distribution || []);
  html += buildRoleSenioritySection(snapshot.role_seniority_mix || null);
  html += buildScoreTierSection(snapshot.score_tier_distribution || []);
  ```
- This goes BEFORE the Opportunity Alerts section (so the intelligence sections appear between enrichment status and alerts).

**Key constraints:**

- All user-provided text wrapped in `escapeHtml()`
- All new build functions return '' for null/undefined/empty input (stale snapshot guard)
- No new CSS rules — use only existing classes from app.css
